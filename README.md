# Snake

Just a simple Snake game written in C++.

## Controls

- W = Up
- A = Left
- S = Down
- D = Right
- P = Pause

## Features

- Automatic movement
- Food spawning
- Score system
- Snake growth
- Wall and self collision
- Window stays open
- Press r to restart
- Press q to quit
- Finalscore
- Food can not spawn on snake
- Snake gets faster every 5 Scorepoints
- Highscore and saving with fstream
- Pause
- Obstacles
